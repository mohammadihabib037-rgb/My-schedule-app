برنامه شخصی «برنامه من»
نسخه ۱

برای استفاده روی گوشی:
1) فایل index.html را روی گوشی باز کن.
2) در Chrome از منوی ⋮ گزینه «Add to Home screen / افزودن به صفحه اصلی» را بزن.
3) فعالیت‌ها در حافظه مرورگر گوشی ذخیره می‌شوند.

امکانات: افزودن، ویرایش، حذف، زمان شروع/پایان، دسته‌بندی، تیک انجام‌شدن، درصد پیشرفت و آمار روزانه.
